# Personal Expense Tracker System

## About the Project
The Personal Expense Tracker System is a Python-based desktop application designed to help users manage their personal finances efficiently. It allows users to record income and expenses, monitor their balance, track spending habits, and maintain better control over their budgets.

## Features
- **User Authentication:** Login and registration functionality.
- **Income Management:** Add and manage income records.
- **Expense Tracking:** Record and manage daily expenses.
- **Balance Monitoring:** View the available balance.
- **Budget Alerts:** Get notified when expenses approach or exceed the set budget.
- **Transaction History:** View and manage financial transactions.
- **Monthly Reports:** Analyze monthly income and expenses.
- **Data Visualization:** View spending patterns through graphical charts.
- **Excel Export:** Export transaction data for further analysis.
- **Database Integration:** Store financial records using SQLite.

## Technologies Used
- **Programming Language:** Python
- **GUI Framework:** Tkinter
- **Database:** SQLite
- **Data Visualization:** Matplotlib
- **Excel Export:** OpenPyXL

## Installation and Setup

### 1. Clone the Repository
```bash
git clone <your-repository-url>
```

### 2. Navigate to the Project Directory
```bash
cd expense-tracker
```

### 3. Install Dependencies
```bash
pip install matplotlib openpyxl
```

### 4. Run the Application
```bash
python main.py
```

*Note: Replace `main.py` with your actual Python entry-point filename if it differs.*

## How to Use
1. Launch the application.
2. Register a new account or log in.
3. Add your income and expense transactions.
4. Monitor your balance and spending.
5. Review monthly reports and charts.
6. Export transaction records to Excel when needed.
